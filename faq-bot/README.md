# よくある質問ボット

質問を入力すると、登録された回答を返すチャット画面です。
社内ヘルプデスク（`../`）とは別のアプリで、単体で動きます。

## AIは使っていません

**キーワードの一致だけで判定しています。** そのため次のようになります。

| | |
|---|---|
| APIキー | **不要** |
| 費用 | **ゼロ** |
| 外部への通信 | **なし** |
| 答えを作ること | **しない**（登録した回答しか返さない） |
| 出典 | 必ず表示する |
| 苦手なこと | 登録していない言い回しは拾えない |

説明するときは「AIチャットボット」ではなく「**登録した回答を返すボット**」とお伝えください。
後からAIに置き換えることもできますが、そのときは APIキーが必要になります。

## 起動

```bash
npm install
npm start          # http://localhost:3100
```

Windows では `npm.cmd start` のように `.cmd` を付けてください。

ヘルプデスクは 3000番、こちらは 3100番なので、**同時に動かせます**。

## 答えの決め方

一致した言葉が多いものを選びます。**同点のときは1件に決めません。**

```
「返品の納期」
  → 納期(delivery) と 返品(return) が同点
  → 「どちらについてのご質問でしょうか」と候補を出して選んでもらう
```

以前は配列の先頭に近いものを返していましたが、**質問の意図と無関係な並び順で決まる**ため
変更しました。分からないものを分からないと言うのが、この仕組みの長所です。

`[応答] matched=ambiguous(...)` がログに増えていたら、**キーワードが重なっている**
合図です。どちらか一方から削ると特定できるようになります。

## 中身を差し替える

`src/faq.json` を編集します。**プログラムではなくデータのファイル**なので、
書き方を間違えても原因が日本語で表示されます。

```json
{
  "id": "warranty",
  "question": "保証期間はどれくらいですか？",
  "keywords": ["保証", "ほしょう", "無償"],
  "answer": "購入日から1年間です。",
  "source": "製品保証規定",
  "updatedAt": "2026-09"
}
```

| 項目 | 内容 |
|---|---|
| `id` | 重複しない名前（英数字） |
| `question` | 画面の例に出る文 |
| `keywords` | この言葉が質問に含まれたら候補にする。**言い換えを並べる** |
| `answer` | 返す文章 |
| `source` | どこに書いてあるか |
| `updatedAt` | `2026-09` の形式。画面に「最終更新」として出る |

**キーワードは他の項目と重ならないようにしてください。** 「修理」を保証とサポートの
両方に入れると、どちらか決められなくなります。

書き方を間違えると、起動時にこう表示されます。

```
FAQのファイルの書き方が正しくありません: src/faq.json
  32 行目のあたりを確認してください。
  よくある原因: 項目の区切りのカンマが多い／足りない、引用符の閉じ忘れ

FAQのファイルに問題があります: src/faq.json
  2 件目: source がありません
  3 件目: id "warranty" が重複しています
```

いま入っているのは**サンプル5件**です。実際の内容に差し替えてください。

## 確認

```bash
npm run check         # 下の2つをまとめて実行（44件）
npm run check:match   # 照合の確認（27件）
npm run check:api     # 異常系とログの確認（17件）
```

**照合の確認（27件）**

1. 登録した5件の質問にすべて答えられる
2. 言い回しを変えても拾える（「保証はいつまで？」など）
3. **同点のときは1件に決めつけない**（候補を返す）
4. **知らないことは答えない**（天気などは「該当なし」）
5. **登録されていない回答を作らない**（返す文はFAQと完全一致）
6. 出典と更新日が必ず付く
7. FAQデータに欠けや重複が無い

**異常系とログの確認（17件）**

1. 壊れたJSON・型違い・空欄・巨大な入力は 400 か 413 で返す
2. そのあともアプリは動き続ける
3. 応答と不正なリクエストがログに残る
4. **ログに質問文とスタックトレースが出ない**

## ログ

出るのは次の2種類だけです。

```
[応答] matched=warranty                    どのFAQに一致したか
[応答] matched=ambiguous(delivery+return)  同点で決められなかった
[応答] matched=none                        該当が無かった
[リクエスト不正] reason=...                 受け取れなかった理由
```

**質問文そのものは記録しません。** 氏名や連絡先が含まれうるためです。

`matched=none` が増えていれば **FAQ に足すべき項目がある**、
`matched=ambiguous` が増えていれば **キーワードが重なっている**と分かります。
ただし何を聞かれたかは残らないので、内容を知りたい場合は利用者に直接確認してください。
質問文も記録する方が改善は早くなりますが、個人情報が残る点との引き換えになります。

## 構成

```
src/
  server.js    起動と2つの経路（画面 / 質問への応答）
  faq.json     FAQデータ ← ここを書き換える
  match.js     FAQの読み込み・検査とキーワード照合
  views/
    chat.ejs   チャット画面
test/
  match.test.js    照合の確認
  check-api.sh     異常系とログの確認
```
