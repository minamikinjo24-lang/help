# よくある質問ボット

質問を入力すると、登録された回答を返すチャット画面です。
社内ヘルプデスク（`../`）とは別のアプリで、単体で動きます。

## AIは使っていません

**キーワードの一致だけで判定しています。** そのため次のようになります。

| | |
|---|---|
| APIキー | **不要** |
| 費用 | **ゼロ** |
| 外部への通信 | **なし** |
| 間違った回答 | **出ない**（登録した回答しか返さない） |
| 出典 | 必ず表示する |
| 苦手なこと | 登録していない言い回しは拾えない |

説明するときは「AIチャットボット」ではなく「**登録した回答を返すボット**」とお伝えください。
後からAIに置き換えることもできますが、そのときは APIキーが必要になります。

## 起動

```bash
npm install
npm start          # http://localhost:3100
```

Windows では `npm.cmd start` のように `.cmd` を付けてください。

ヘルプデスクは 3000番、こちらは 3100番なので、**同時に動かせます**。

## 中身を差し替える

`src/faq.js` を編集するだけです。

```js
{
  id: 'warranty',                      // 重複しない名前
  question: '保証期間はどれくらいですか？',  // 画面の例に出る文
  keywords: ['保証', 'ほしょう', '修理'],   // この言葉が質問に含まれたら候補にする
  answer: '購入日から1年間です。',          // 返す文章
  source: '製品保証規定',                  // どこに書いてあるか
}
```

**`keywords` には言い換えを並べてください。** 「見積」だけだと「みつもり」で聞かれたときに拾えません。
一致した言葉が多いものが優先されます。

いま入っているのは**サンプル5件**です。実際の内容に差し替えてください。

## 確認

```bash
npm run check
```

16件を確認します。

1. 登録した5件の質問にすべて答えられる
2. 言い回しを変えても拾える（「保証はいつまで？」など）
3. **知らないことは答えない**（天気などは「該当なし」）
4. **登録されていない回答を作らない**（返す文はFAQと完全一致）
5. 出典が必ず付く

## 構成
