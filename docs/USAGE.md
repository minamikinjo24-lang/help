# 使い方

技術的な知識がなくても操作できるように書いています。
開発者向けの詳細は [README.md](../README.md) を参照してください。

## 毎回の起動と終了

### 起動する

1. Windows キーを押して `powershell` と入力し、**Windows PowerShell** を開く
2. 次の2行を1行ずつ貼り付けて Enter

```
cd C:\helpdesk\help-claude-internal-helpdesk-design-k6udmr
```
```
npm.cmd start
```

3. `社内ヘルプデスク: http://localhost:3000` と表示されたら起動成功
4. Chrome のアドレス欄に `localhost:3000` と入力して Enter

**PowerShell の画面は閉じないでください。** 閉じるとアプリが止まります。

### 終了する

PowerShell の画面で **Ctrl + C** を押します。

## 画面の使い方

### ログイン

`localhost:3000` を開くとログイン画面になります。「ログインする」を押し、Google アカウントを選びます。

「このアプリは Google で確認されていません」と出たら、「詳細」→「helpdesk に移動」→「続行」と進みます。テスト中のアプリでは必ず出る表示で、問題ありません。

### 問い合わせを登録する

1. 一覧画面の「新規作成」をクリック
2. タイトル（必須）、内容、優先度を入力
3. 「登録する」をクリック

タイトルが空だと登録できません。

#### 分類案について

タイトルや内容を入力すると、**優先度案・カテゴリ案・理由**が自動で表示されます。

「この提案を採用する」を押すと、下の入力欄にその値が入ります。押さなければ何も変わりません。
提案が的外れなときは無視して、自分で選んでください。

判定は「印刷」「Wi-Fi」「至急」といった**言葉の一致**で行っています。当てはまる言葉が
無いときは「判断不能」と表示され、採用してもカテゴリは空のままです。AIは使っていないので、
費用はかかりません。

### 一覧を見る

ログインすると一覧が表示されます。見える範囲は権限によって変わります。

| 権限 | 見える範囲 |
|---|---|
| 一般（general） | 自分が登録したものだけ |
| 担当（agent） | 全件 |
| 管理者（admin） | 全件 |

### 詳細を見る／後から分類する

一覧の**タイトルをクリック**すると詳細画面が開きます。内容の全文と、登録日時・更新日時が見られます。

担当・管理者の権限があれば、詳細画面に「分類案を出す」ボタンが出ます。

1. 「分類案を出す」を押す → 優先度案・カテゴリ案・理由が表示される
2. 内容を確認して「この分類案を採用して保存する」を押す → 保存される

**押すまでは何も変わりません。** 案が的外れなら、そのまま閉じて構いません。

### 削除する

**管理者だけ**が一覧に「削除」ボタンを見られます。押すと確認が出て、OK すると消えます。**元に戻せません。**

## 権限の設定

`.env` というファイルで決めます。変更するには PowerShell で次を実行します。

```
notepad .env
```

```
ROLE_ADMINS=管理者のメールアドレス（カンマ区切り）
ROLE_AGENTS=担当者のメールアドレス（カンマ区切り）
```

ここに書かれていない人は全員「一般」になります。保存したらアプリを再起動してください。

**変更後は一度ログアウトして、ログインし直す必要があります。** 権限はログインしたときに決まるためです。

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| `このサイトにアクセスできません` | アプリが起動していません。上の「起動する」をやり直してください |
| `redirect_uri_mismatch` | Google 側の設定と食い違っています。[README](../README.md) の「Google でログインする設定」を確認 |
| `アクセスをブロックしました` | Google Cloud Console のテストユーザーに自分が入っていません |
| 権限を変えたのに反映されない | ログアウトしてログインし直してください |
| 削除ボタンが出ない | 管理者権限がありません。`ROLE_ADMINS` を確認してください |

上記で解決しない場合は、**PowerShell に出ている文字**と**ブラウザの画面**の両方を控えておくと原因を特定しやすくなります。

## 動作確認

アプリが正しく動くかを自動で確認できます。

```
npm.cmd run check
```

権限まわりと基本動作を47項目チェックします。すべて `OK` なら正常です。

```
npm.cmd run repro
```

ログに必要な情報が残るかを12項目チェックします。

どちらも外部サービスを使わず、ローカルだけで完結します。

## 注意点

- **データはこのパソコンの中にだけあります**（`data\help.db`）。他の人からは見えません
- 問い合わせの**編集機能はありません**。内容を直したい場合は登録し直してください
- 分類案は登録時と詳細画面の両方で出せます。詳細画面からは何度でもやり直せます
- 詳細画面で変更できるのは**優先度とカテゴリだけ**です。タイトルと内容は直せません
- 作成者は記録されますが、**過去に登録したものは作成者が空**です。一般権限では見えません
