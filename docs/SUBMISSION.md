# 課題提出：よくある質問ボット

「社内ヘルプデスクを作ったときと同じやり方で、別のものを作ってみる」課題として、
**よくある質問に答えるボット**を作りました。

---

## 作ったもの

質問を入力すると、登録された回答を返すチャット画面です。

```
あなた: 保証期間は？
ボット: 購入日から1年間です。延長保証をお申し込みいただくと3年間になります。
        出典: 製品保証規定（最終更新 2026-09）

あなた: 返品の納期
ボット: どちらについてのご質問でしょうか。選んでください。
        [納期はどれくらいかかりますか？] [返品はできますか？]

あなた: 今日の天気は？
ボット: 申し訳ありません。その質問にはお答えできる情報がありません。
        担当者へお問い合わせください。
```

動かし方: `cd faq-bot` → `npm install` → `npm start` → ブラウザで `localhost:3100`

---

## 最初に決めたこと

**作るもの**：質問に答える画面、キーワードによる照合、FAQデータ

**作らないもの**：ログイン、データベース、質問履歴の保存、AI

AIを使わなかったのは、**APIキー（クレジットカード登録と利用料）が必要**だったためです。
使えない条件の中で、同じ目的をどう達成するかを考えました。

---

## 同じ工程を踏んだ記録

### 1. テストを先に書いた

実装を直す前にテストを書き、実行しました。**6件落ち、うち2件が本当の不具合**でした。

| 見つかった不具合 | 内容 |
|---|---|
| 文字列以外の質問が通っていた | 数値や配列がそのまま質問として扱われ、エラーにならないので気づけない状態 |
| ログにスタックトレースが出ていた | 内部のファイル構成が残り、ログが読めなかった |

残る4件はテスト側の書き方の誤りで、実装の問題ではありませんでした。

### 2. 異常系を試した

壊れたデータ、型違い、巨大な入力、存在しないパスを実際に送り、
**適切なエラーを返してアプリが動き続けること**を確認しました。

### 3. ログを整えた

記録するのは「どのFAQに一致したか」だけにしました。
**質問文そのものは残しません**（氏名や連絡先が含まれうるため）。

### 4. レビューして直した

権限・秘密情報・異常系の観点で見直し、**重大2件・中程度2件**を修正しました。

| 指摘 | 内容 | 対応 |
|---|---|---|
| 見当違いの回答を返す | 一致数が同じとき、データの並び順で答えが決まっていた | 同点なら決めつけず候補を出す |
| 候補を1件しか見せない | 他に該当があっても伝えていなかった | 候補をボタンで並べる |
| データを壊すと起動しない | プログラムのファイルに埋まっていた | データファイルに分け、誤りを日本語で表示 |
| 回答の鮮度が不明 | 古い情報を返し続ける恐れ | 更新日を必須にし画面に表示 |

**一番大きかったのは1つ目です。** 「修理の完了時期」を聞いているのに
「保証期間は1年です」と返していました。答えを作ってはいないものの、
関係ない回答を正解のように出していたことになります。

---

## 確認方法

```
npm run check      # 44件（照合27 + 異常系17）
```

すべてローカルで完結します。外部サービスもAPIキーも不要です。

確認している内容：

- 登録した質問に答えられる／言い回しが違っても拾える
- **同点のときは1件に決めつけない**
- **知らないことは答えない**
- **登録されていない回答を作らない**（返す文はデータと完全一致）
- 出典と更新日が必ず付く
- 異常な入力でもアプリが止まらない
- **ログに質問文とスタックトレースが出ない**

## 正直に書いておくこと

| 項目 | 状態 |
|---|---|
| 実際の業務での利用 | **していません。** 手元で動く段階です |
| AIの利用 | **していません。** キーワード判定です |
| FAQの中身 | **サンプル5件**です。差し替えられる形にしてあります |
| 公開 | していません。ログインが無いため、公開前に追加が必要です |

未対応のまま残した課題もあります（公開時のログイン、回数制限）。
**把握したうえで、今回の範囲では作らない判断をした**ものです。

---

## 学んだこと

**「動いた」と「動いている」は違いました。** 画面で確認して満足していたものに、
テストを書いたら不具合が残っていました。しかも自分では気づけない種類のものでした。

**作らない判断にも理由が要ります。** AIを使わない、ログインを作らない、と決めるたびに
「なぜ今は不要か」「必要になったら何をするか」を書き残しました。
後から読み返せる形にしておくと、次の判断が早くなります。

**一番時間がかかったのは環境構築でした。** Node.jsのインストール、PowerShellの設定、
フォルダの場所の食い違い。アプリ本体より、そこに至るまでの方が大変でした。
