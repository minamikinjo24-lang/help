# 日報作成

やったことを1行ずつ書くと、**いつもの形式の文章**ができます。コピーして LINE に貼ってください。

社内ヘルプデスク（`../`）、よくある質問ボット（`../faq-bot`）とは別のアプリです。

## 何が楽になるか

毎回打ち直していた**挨拶と締めが自動**になります。書くのは中身だけです。

```
入力                          出力
─────────────────────────────────────────
A社への見積もり作成      →   お疲れ様です。
定例会議に出席                本日の業務報告です。
在庫の確認
                              ・A社への見積もり作成
                              ・定例会議に出席
                              ・在庫の確認

                              以上です。
                              よろしくお願いいたします。
```

おまけとして、過去の日報を見返せます。「前回の内容を読み込む」で下敷きにもできます。

## LINEへの自動送信はできません

LINEに自動で投稿するには、会社のLINE公式アカウントとアクセストークンが必要で、
個人のLINEには送れない仕組みです。**コピーして貼る**ところまでになります。

## 起動

```bash
npm install
npm start          # http://localhost:3200
```

Windows では `npm.cmd start` のように `.cmd` を付けてください。

ヘルプデスクは3000番、ボットは3100番、こちらは3200番なので**同時に動かせます**。

## 形式を変える

`src/format.js` の `TEMPLATE` を書き換えます。

```js
const TEMPLATE = {
  greeting: ['お疲れ様です。', '本日の業務報告です。'],
  bullet: '・',
  closing: ['以上です。', 'よろしくお願いいたします。'],
};
```

行を足せば、その分だけ出力に増えます。

## 入力の揺れは吸収します

- 先頭に `・` `-` `*` を付けて書いても、二重になりません
- 前後の空白は取り除きます
- 空行は無視します

## 確認

```bash
npm run check          # 下の2つをまとめて実行（36件）
npm run check:format   # 文章の組み立て（14件）
npm run check:api      # 異常系とログ（22件）
```

確認している内容：

- いつもの形式どおりに出力される
- 入力の揺れを吸収する
- 何も書かなければ作らせない
- 壊れたJSON・型違い・巨大な入力でも止まらない
- **ログに業務の中身が出ない**

## ログ

```
[日報作成] date=2026-09-18 items=3     作成した日付と件数
[リクエスト不正] reason=...            受け取れなかった理由
```

**業務の内容は記録しません。** 件数だけです。

## データ

`data/reports.db`（SQLite）に保存します。**このパソコンの中だけ**にあり、他の人からは見えません。

| カラム | 内容 |
|---|---|
| `report_date` | 日付 |
| `items` | 入力した内容（そのまま） |
| `created_at` | 作成日時 |
